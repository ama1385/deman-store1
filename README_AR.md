# DEMAN.STORE — Vercel Ready

هذه نسخة Vercel مبنية من النسخة المسترجعة من Cloudflare.

## الموجود
- المتجر الرئيسي + صفحة تفاصيل المنتج.
- لوحة التحكم `/admin/`.
- المنتجات الأربعة الحالية ووصفها وأسعارها وصورها كبيانات Seed.
- API للمنتجات والإعدادات وتسجيل الدخول ورفع الصور.
- تخزين التعديلات والصور الجديدة في **Private Vercel Blob**.
- الصور الأصلية المسترجعة موجودة محليًا داخل `images/products/`، لذلك تظهر حتى قبل تهيئة Blob.

## قبل النشر — 3 أشياء فقط
1. ارفع هذا المجلد إلى مشروع Vercel.
2. من مشروع Vercel افتح **Storage** وأنشئ **Blob** واختر **Private** واربطه بالمشروع. المتاجر الجديدة تدعم OIDC تلقائيًا، لذلك لا تحتاج تحط توكن طويل داخل الكود.
3. أضف Environment Variables:
   - `ADMIN_PASSWORD` = كلمة مرور جديدة للوحة التحكم.
   - `SESSION_SECRET` = قيمة عشوائية طويلة (يفضل 32+ حرف).

## نشر من التيرمنال
```bash
npm install
npx vercel
npx vercel --prod
```

بعد ربط المشروع، لو تحتاج تشغيل محلي ببيئة Vercel:
```bash
npx vercel link
npx vercel env pull .env.local
npx vercel dev
```

## فحص بعد النشر
- `/` المتجر.
- `/product.html?id=perf-day` صفحة منتج.
- `/admin/` لوحة التحكم.
- `/api/health` حالة إعدادات لوحة التحكم.

## ملاحظات مهمة
- القراءة تستخدم بيانات الاسترجاع كـ fallback إلى أن تحفظ أول تعديل. أول حفظ للمنتجات أو الإعدادات ينشئ JSON دائم داخل Blob.
- رفع الصور من لوحة التحكم محدود إلى 2MB وPNG/JPG/WEBP مثل النسخة الأصلية.
- يوجد `/api/export` (يتطلب جلسة Admin وHeader لوحة التحكم) لتصدير البيانات برمجيًا إذا احتجت نسخة احتياطية.
- لا تحذف مشروع Cloudflare القديم قبل اختبار Vercel بالكامل.

## ماذا تم تغييره عن Cloudflare؟
- Cloudflare Pages Functions + KV استُبدلت بـ Vercel Functions + Private Vercel Blob.
- روابط API بقيت بنفس الشكل حتى تستمر الواجهة ولوحة التحكم بالعمل.
- صورة التحويل البنكي لم تكن ضمن ملفات الاسترجاع، لذلك أضيف رمز بنك SVG محلي بدل الرابط القديم المفقود.


## المعاينة بدون Vercel
إذا فتحت `index.html` مباشرة من ويندوز، ستظهر المنتجات الأربعة والصور من نسخة الاسترجاع المحلية. لوحة التحكم والكتابة تحتاج تشغيل Vercel (`npx vercel dev`) أو النشر الفعلي لأن عمليات `/api` تحتاج سيرفر.
